  matrix; fixed-wall RPA comparison; complete boiling benchmark definition,
  energy balance, applicability and warnings.

- `github_publication.json`: confirmed private prerelease, code commit,
  uploaded asset IDs/sizes and matching GitHub SHA-256 digests.

The boiling cylinder uses specified constant-gamma gas screening properties,
not a CEA or hot-fire validation. Subcooled boiling before bulk saturation is
unsupported; the displayed single/two-phase handoff is not a validated smooth
physical transition. Full numerical completion and energy closure do not imply
the overall applicability is valid. CHF/dryout and mixture boiling are not
predicted. See [implementation record](../THERMAL_BETA_2026-10-19.md).
