# Engine Definition 추진제 검토 — LPA 0.11.0

> 이 문서는 당시 버전의 검토 이력입니다. 0.14.0의 EOS·공급 엔탈피·열전달 수정과 현재 적용범위는 [2026-10-11 수정 및 신뢰도 평가](RELEASE_REMEDIATION_2026-10-11.md)를 참조하십시오.

검토일: 2026-09-18 KST. 대상: CPython 3.14 / RocketCEA 1.2.3의 실제 입력 카드, LPA 엔진 입력·저장·성능·자동 O/F·냉각제 연결 경로.

## 조성 및 단위

- H2O2, Ethanol, IPA 입력은 **질량 백분율**이며 `0 < wt% ≤ 100`이다. 예를 들어 Ethanol 70%는 에탄올 0.7 kg와 물 0.3 kg이다. 체적 백분율이나 몰 백분율로 해석하지 않는다.
- Core에는 `oxidizer_mass_fraction`, `fuel_mass_fraction`을 0–1 범위로 저장한다. GUI/CFG의 `*_mass_fraction_pct`는 0–100 단위다. 희석되지 않는 추진제의 core 분율은 1이다.
- O/F는 물을 포함한 전체 산화제 질량유량 / 전체 연료 질량유량이다. 각 CEA 공급류 카드의 `wt%` 합은 100이다. 100%에서는 0 질량 물 성분을 제외한다.
- 70/80/90/100% 레거시 enum 및 기존 CFG/JSON 이름은 읽을 수 있다. UI에서는 단일 종류와 별도 분율로 복원한다. 기존 이름의 농도가 이행 전 입력의 기준이다.
- 수용액의 반응물 엔탈피는 순수 액체 성분 엔탈피의 질량 가중 합이며 비이상 혼합열은 포함하지 않는다. CEA가 계산하는 연소 생성물 평형 물성과, 아래 냉각 유체의 screening 물성 모델은 구별한다.

## 전체 추진제 카드 대조

핀 고정된 RocketCEA `input_cards.py` 및 `thermo.inp`와 [공식 추진제 설명](https://rocketcea.readthedocs.io/en/latest/propellants.html)을 대조했다. 아래 온도는 **Engine Definition 성능 계산에 사용되는 반응물 기준 온도**이며 Regen의 사용자 입력 온도와 독립적이다. 현재 엔진 입력에는 별도의 공급 온도/압력 상태 모델이 없다.

| Engine 선택 | CEA 상태/기준 온도 | 적용 및 검토 결과 |
|---|---|---|
| LOX | O2(L), 90.18 K | 기존 `LOX` 액체 카드 유지 |
| GOX | O2(G), 298.15 K | 기존 `GOX` 기체 카드 유지 |
| H2O2 | H2O2(L) + H2O(L), 298.15 K | 사용자 질량분율로 생성; 순수 H2O2의 h = −187.77792 kJ/mol, 물은 −285.830 kJ/mol |
| N2O | 액체 정상비점 기준, 184.4 K | 기존 `N2O`는 298.15 K 기체 엔탈피였으므로 `N2O_nbp`로 수정 |
| Ethanol | C2H6O(L) + H2O(L), 298.15 K | 사용자 질량분율로 생성; 순수 액체 h = −277.69108 kJ/mol; 100%는 기존 CEA 순수 액체 카드와 일치 |
| IPA | C3H8O(L) + H2O(L), 298.15 K | 신규 액체 카드, h = −318.2 kJ/mol. RocketCEA 기본 `Isopropanol`의 −65133 cal/mol(약 −272.516 kJ/mol)은 기체 값이므로 사용하지 않음 |
| RP-1 | 대표 C/H 액체 연료, 298.15 K | 유효 alias `RP-1`을 정식 카드 키 `RP1`로 통일; 화학 모델은 동일 |
| Jet A-1 | Jet-A(L) 대체 조성 C12H23, 298.15 K | 기존 `JetA` 유지; 특정 lot/등급의 실제 분석 조성을 뜻하지 않음 |
| LCH4 | CH4(L), 111.66 K | 기존 액체 메탄 카드 유지 |
| LNG | 아래 상용 대표 조성의 액체 기준 성분 혼합 | 별도 `LPA_LNG_TYPICAL` 카드; 순수 LCH4와 구분 |
| GCH4 | CH4(G), 298.15 K | 기존 기체 메탄 카드 유지 |
| LH2 | H2(L), 20.27 K | 기존 액체 수소 카드 유지 |
| GH2 | H2(G), 298.15 K | 기존 기체 수소 카드 유지 |
| Propane | C3H8(L), 231.08 K | 기존 액체 카드 유지; 잘못된 `gas` 메타데이터를 `liquid`로 수정 |

IPA 액체 생성엔탈피는 [NIST Chemistry WebBook, isopropyl alcohol](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67630&Mask=2)의 Snelson and Skinner (1961) 값 −318.2 ± 0.71 kJ/mol을 사용한다. 같은 페이지의 기체 데이터와 비교해 상 구분을 확인했다. 모든 신규 카드의 엔탈피 단위는 명시적인 `h,kj/mol`이다.

## 상용 LNG 기준

상용 LNG에는 전 세계가 사용하는 하나의 고정 조성이 없으므로, 사용자가 요청한 일반 판매품을 대표하는 기준으로 [Wärtsilä의 typical natural gas](https://www.wartsila.com/encyclopedia/term/natural-gas-(dry)) 조성을 채택했다. 원문의 기체 체적비를 몰분율로 해석하고 `w_i = x_i M_i / Σ(x_j M_j)`로 변환한다. 부탄 이성질체는 원문에 없으므로 n-butane을 대체 성분으로 선택했다.

| 성분 | 몰% | 질량% | 액체 기준 T, K | 기준 h, kJ/mol |
|---|---:|---:|---:|---:|
| CH4 | 94.0 | 88.46491505 | 111.66 | −89.495760 |
| C2H6 | 4.7 | 8.29067072 | 184.56 | −103.750648 |
| C3H8 | 0.8 | 2.06946310 | 231.08 | −127.076448 |
| n-C4H10 | 0.2 | 0.68193705 | 272.638 | −150.664000 |
| N2 | 0.3 | 0.49301408 | 77.352 | −12.107000 |

평균 분자량은 17.04620684 kg/kmol이다. CH4/C2H6/C3H8는 RocketCEA의 액체 카드, n-butane/N2는 동봉 NASA `thermo.inp`의 McBride (1996) 액체 반응물 데이터를 사용한다. 위 카드의 질량비와 원소 수는 실제 조성으로 적용된다.

엔탈피는 각 성분의 **표에 적힌 액체 기준 상태**를 혼합하는 예비 모델이다. 하나의 공통 LNG 온도에서의 실제 용액 상태, 성분별 과냉각 sensible enthalpy, 혼합열, 상평형/boil-off는 해석하지 않는다. 이 제한을 숨기고 모든 성분이 111.66 K에서 평가되었다고 취급하지 않는다. 공급사 성적서 조성과 혼합물 EOS가 필요한 정밀 상태 계산은 별도 모델이 필요하다.

## 냉각 물성과 fallback 검토

- Engine oxidizer/fuel에서 시작하는 Regen 및 연결 Regen/Film은 `Ethanol (73.125%)`와 같이 실제 농도를 유지한다. 형식 변환 중 70/80/90/100%로 반올림하지 않는다. Film 오리피스 밀도도 같은 조성의 모델을 사용한다.
- 기존 H2O2/Ethanol 70–100% 냉각 물성 anchor를 유지하고 그 사이 농도를 보간한다. 그 이하와 IPA 수용액에는 비체적 기반 밀도, 질량 기준 비열, 선형 열전도도 및 로그 점도 혼합을 적용한다. 이는 screening 추정으로 실제 알코올–물의 부피 수축, 과잉 비열, 비선형 점도 최대값을 재현하는 실험 상관식이 아니다.
- IPA의 293.15 K 기준은 ρ=785 kg/m³, cp=2680 J/(kg·K), k=0.135 W/(m·K), μ=2.04 mPa·s의 대표 액체 screening 값이다. LNG의 ρ=450 kg/m³는 위 Wärtsilä 자료, cp=3400 J/(kg·K), k=0.185 W/(m·K), μ=0.13 mPa·s는 극저온 액체의 screening 추정이다.
- 다른 냉각제의 기존 밀도·비열·열전도도·점도 표와 온도 보정 모델은 유지한다. 특히 GOX/GCH4/GH2의 밀도는 지정 고압의 대표값이며 현재 온도만으로 보정한다. 국부 압력에 따른 기체/초임계 유체 EOS나 비등/두 상유동을 검증한 모델은 아니다. 정밀 열/압력손실 해석에서는 기존 `coolant_properties` override 경로를 이용할 수 있다.
- fallback의 이전 H2O2/N2O O/F 계수는 유효 산소 질량이 작아졌는데도 필요한 산화제 질량을 줄이는 방향이었다. 이를 H2O2의 16/34, N2O의 16/44 산소 질량비로 수정하고 연료 희석은 O/F를 낮추고 산화제 희석은 O/F를 높이도록 했다. fallback의 온도·분자량·γ는 공학적 근사이며 CEA 물성으로 표시하지 않는다.

## C* 최적화와 검증

자동 O/F는 CEA의 `get_Cstar(Pc, MR)`를 최대화한다. 유한 수축비와 공급 조성을 동일 객체에 적용한다. 출구면적/외압 및 downstream frozen 선택은 선택된 O/F의 Isp·출구 상태 계산에만 쓰며 C* 목적함수에는 넣지 않는다. 직접 Dc+명목 추력의 경우 목 면적과 유효 Ac/At를 반복 수렴한다. 전역 탐색 범위는 기존 0.1–30이며 경계에 도달하면 표시한다.

RocketCEA 1.2.3, LOX/Ethanol, Pc=20 bar(a), Ac/At=6.25, 출구 1 atm에서 확인한 값:

| 에탄올 질량% | C* 최적 O/F | C*, m/s |
|---|---:|---:|
| 70 | 1.23479916 | 1636.0857 |
| 73.125 | 1.26771467 | 1646.3445 |
| 100 | 1.52146382 | 1720.4167 |

기본 엔진의 O/F=1.3은 사용자 지정값이므로 자동 선택을 해제한 상태로 유지한다.

`tests/test_propellant_composition.py`, `tests/test_core_performance.py`, `tests/test_ui_smoke.py`에서 다음을 검증했다.

- 실제 RocketCEA의 4개 산화제 × 10개 연료 40조합이 fallback 없이 유한한 결과를 낸다.
- 수용액 카드 질량 합, 소수점 농도 유지, 농도별 CEA 캐시 분리, 순수 100% endpoint와 기존 액체 카드의 수치 일치.
- C*와 Isp의 최대점이 다른 시험 함수에서 C* 최대점을 선택한다. 실제 CEA의 최적 O/F 인근 ±0.01/±0.05에서 C*가 더 낮으며 출구면적 5/50 및 1 atm 출구로 바꿔도 최적 O/F가 유지된다.
- 저장·재열기·레거시 이행·농도 입력 유효성·Regen/Film 조성 전달·기본 엔진·1080×700에서 모든 추진제 선택의 레이아웃.

전체 테스트 실행 결과: **209 passed** (2026-09-18 KST). 이 결과는 위 소프트웨어 동작과 명시한 물성/조성 경로에 대한 검증 기록이다.
